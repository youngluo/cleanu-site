## Why

官网已展示 $9 一次买断与 30 天试用，但购买按钮禁用，尚无支付回跳、许可证领取说明或购买支持流程。需要在现有 Astro 静态架构中接入 Dodo 托管结账，与 App 的试用和激活规则一致。

## What Changes

- 通过 Dodo 静态 Payment Link 开放购买，不增加服务端或浏览器商户密钥；保持一份购买生成一把永久许可证，最多同时激活 2 个安装实例。
- 保留现有 $9 一次性价格、30 天完整试用和永久更新，将中英文的三台设备改为两台，首页说明试用到期后需购买激活，购买条款披露付费授权的七天离线限制；首页移除离线验证说明，不展开后台校验频率。
- 新增中英文购买回跳页和购买条款页。回跳页只展示引导性支付状态与邮件激活步骤，不把查询参数当作真实支付或授权凭据。
- 商品开启自动许可证发放，由 Dodo 邮件交付。用户复制许可证到 App 激活，网页不调用激活接口、不自动启动清理。
- 补充 Dodo 购买邮件中的支持入口、换机及邮件未收到指引，联系时提供购买邮箱、必要订单信息与问题描述，不依赖 App 内支持或复制编号入口；支持邮箱只在 Dodo 后台配置，不进入网站、App 或仓库；购买政策采用不提供无理由退款、保留适用法律及平台要求例外的表述。
- 更新隐私政策，区分本地扫描、更新检查、Dodo 支付和定期授权校验；限制回跳地址中许可证和邮箱的进一步传播。
- 正式购买仅在兼容的 App 已发布、公开配置完整且测试链路验收后开放。本轮已实现静态页面与构建校验，并完成 Test Mode 购买、自动邮件交付和本地回跳；支持邮箱由 Dodo 后台管理，原生 App 联调及发布仍待完成，购买保持关闭。
- 购买配置仅保留正式商品、购买链接及开放开关；App 兼容性和真实购买链路由上线验收确认并记录，不设置最低授权版本和验收记录位置的必填变量。

## Capabilities

### New Capabilities

- `site-checkout`：静态托管结账、双语购买说明与条款、支付回跳隐私、Dodo 订单邮件支持指引以及购买开放条件。

### Modified Capabilities

无已发布主规格需要修改。既有 add-site-localization 的路由、翻译和发布架构继续适用，不把支付工作混入该 change；新增页面及其文案由本能力覆盖。

## Impact

- 涉及 src/components/HomePage、PrivacyPage、SupportPage，新增购买回跳与条款共用组件及两种语言的薄页面入口；路由与全部文案继续由 src/i18n 和 locale JSON 管理。
- 购买配置在构建时校验；公开商品和结账地址用于生成购买链接，支持邮箱仅留在 Dodo 后台。静态 Payment Link 的 redirect_url 按页面语言与部署子路径生成。
- 扩展现有翻译、路由和静态产物校验，保持下载、appcast 与完整 Publish 流程，不添加另一条部署路径。
- 配套 App change 位于相邻 clean-mac 仓库 openspec/changes/integrate-dodo-payments，App 激活结果是能否使用的依据；网页状态不授予权益。
- 正式公开配置中的商品和购买链接在准备完成前保持空值；测试商户和商品仅留作历史联调记录。支持邮箱由 Dodo 后台管理，不复制到代码；正式商品、税费展示及最终购买条款仍需核对。

## 上线 review 补充

支持页、回跳与条款提供 Dodo 客户门户和官方支持页面，邮件未收到或无法登录时仍可直接联系，不在本站保存邮箱。双语试用条款同步为用户点击开始并成功保存起点后计时。官网仅使用生产 Dodo 结账，移除环境字段、测试主机与测试商品默认值，沿用一套正式购买配置和原 Publish 命令；环境命令调整仅属于 macOS App。

发版链路复核移除官网未实际使用的商户 ID 输入；商户归属仍由 App 核对激活响应。网站页面、文案、交互和现有下载发布流程保持一致。
